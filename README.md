# Java Programs 🚀

Welcome to the **Java-Programs** repository! 👩‍💻

This repository contains a collection of Java programs created to strengthen Core Java fundamentals, logical thinking, problem-solving skills, and programming practice. It is especially useful for beginners, freshers, job seekers, and technical interview preparation.

## 📂 Folder Structure

### 🧠 Basic Programs
Programs covering fundamental Java logic and problem-solving concepts:
  - Arithmetic operations  
  - Loops and Conditional Statements 
  - Number-based Programs
  - Prime, Factorial, and Perfect Number Programs
  - Palindrome and Reverse Number Programs
  - Even and Odd Number Programs
  - Positive and Negative Number Programs
  - Fibonacci Series
  - Natural Numbers
  - Power and Square Root
  - ASCII Values
  - Vowel and Consonant
  - Leap Year
  - Swapping Numbers
  - Validation Programs
  - Temperature Conversion
  - Area Calculations
  - And more 

⭐ Pattern Programs  
Programs focused on nested loops, rows, columns, spacing, and pattern-building logic:
  - Binary Patterns
  - Star Patterns
  - Right Triangle Patterns
  - Centered Triangle Patterns
  - Inverted Triangle Patterns
  - Number patterns
  - Number Triangle Patterns
  - Alphabet patterns
